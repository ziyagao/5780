Week 5: Data Practices

Building on our Week 4 dataset, this workshop framed visualisation as both a communication tool and investigative method. My group reflected on challenges in dataset construction, data limitations and power within data workflows. Visual design shapes how audiences interpret results; charts do not simply “show facts”.

Before creating charts, we identified target audiences and core messages to guide visual outputs. We used Excel to create descriptive charts and matched chart types to different variable relationships.
