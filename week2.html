Week 2: Creating Websites

This week pushed me to see the internet not as a borderless, neutral space, but a set of uneven networks shaped by culture and commercial platforms. Examining how proprietary algorithms manage attention, and how communities use “algospeak” or meme tactics to resist suppression, showed me online visibility is always contested. Building this portfolio site with basic HTML and CSS felt freeing compared to scrolling polished social media feeds. Working directly with code helped demystify web infrastructure and turned reflection into an active practice.

Three web-building routes were covered: CampusPress, manual HTML/CSS coding and GitHub Pages. CampusPress is Leeds’ WordPress CMS, offering quick no-code site building with themes but limited customisation, suitable for portfolio blogs.

I practised writing basic HTML for page structure and CSS for styling. I set up a GitHub account, created a repository and activated GitHub Pages to publish my site publicly. I gained understanding of repositories, README files and open-source templates.
