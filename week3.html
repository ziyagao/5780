Week 3: Web Scraping

Web scraping extracts structured data from public web pages for digital media research. Two approaches were demonstrated: the no-code WebScraper.io Chrome extension and Python scraping via Google Colab.

Using WebScraper.io, I located HTML elements, set selectors and exported results as CSV files. Importantly, scraping only captures data visible within webpage code and cannot capture nuanced qualitative context. Many platforms restrict scraping to protect content and user data.
